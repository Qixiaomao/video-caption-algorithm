# Fixed-caption versus multi-reference overfit trial: preregistered protocol

Locked before observing training results, 2026-09-05.

## Question

Does changing the target caption across visits prevent the repaired model from
learning a stable video-specific prefix? This trial is designed to decide
whether a longer full-MSVD training run is justified and which caption policy
it should use. It is not a generalization result or paper-ready evidence.

## Arms and matched controls

- **A_fixed:** each of the same sixteen MSVD training videos always uses the
  canonical caption from the passed overfit16 trial.
- **B_multi:** each video cycles through all of its original MSVD references.
  A per-video permutation is generated once from a SHA-256-derived seed, then
  repeated. Across 250 visits, every stored reference is used four to eleven
  times depending on that video's reference count.
- Both arms use original local GPT-2, pretrained ViT-B/16, prefix length four,
  and exactly the same fresh model initialization.
- Freeze GPT-2 and the ViT backbone. Train only `encoder.proj` and
  `decoder.mapper`; use no historical visual weights and no InfoNCE.
- Seed 123, batch size 8, 8 frames at 224x224, maximum 64 caption tokens,
  AdamW, constant learning rate 3e-4, weight decay 0.01. No AMP, scheduler,
  clipping, accumulation, or early stopping.
- Exactly 500 optimizer steps (250 visits per video), with fixed evaluations at
  steps 0, 50, 100, 250, and 500.
- The complete video-batch schedule is generated by a dedicated seed before
  training and shared by both arms. Caption schedules do not consume the model
  RNG. Pre-forward Python/CPU/CUDA RNG states, video IDs, and visual feature
  tensors must match at all 500 steps; only caption IDs may differ.
- Full causal caption supervision includes the first word and first EOS.

## Frozen-backbone cache

The treatment concerns caption targets, not image decoding or the frozen ViT.
The sixteen real video tensors are loaded through the production loader. The
raw pooled 768-dimensional ViT features are then cached and shared by both
arms, while the trainable 768-to-256 projection remains inside the training
graph. Caching is allowed only if `encoder.proj(cached_feature)` agrees with a
direct `encoder(video)` result to maximum absolute error <=1e-6 before
training. The equivalence check is repeated after each arm.

## Endpoints

At every milestone, evaluate the canonical caption under native and fixed
shuffled prefixes and run deterministic greedy generation. Report native NLL,
shuffled-minus-native NLL, positive-mismatch videos, exact canonical matches,
unique outputs, largest template, EOS termination, and native-versus-shuffled
caption changes.

At the final step 500, additionally score all 668 stored references with equal
reference weighting inside each video and equal video weighting overall.
Report native NLL, shuffled-minus-native NLL, and the number of videos with a
positive mismatch penalty. Generation also reports exact match against any
stored reference and maximum token-F1 against the references; token-F1 is a
triage statistic, not a benchmark metric.

## Decision rule for full-MSVD training

`B_multi` is considered ready for a long full-data run only if all of the
following hold at step 500:

- all-reference native NLL <=2.50;
- all-reference shuffled-minus-native NLL >=1.00;
- at least 14/16 videos have positive all-reference mismatch penalties;
- at least 12/16 native generations change under a shuffled prefix;
- at least 12/16 native captions are unique;
- at least 15/16 native captions terminate with EOS.

Interpretation is fixed in advance:

1. If `B_multi` passes, a long full-MSVD run is justified using a logged,
   balanced multi-reference schedule and increased per-video exposure.
2. If `B_multi` fails while `A_fixed` retains strong canonical binding, do not
   repeat the old random-caption full run. Stabilize targets first (fixed or
   representative captions, or an explicitly balanced curriculum).
3. If both arms fail, do not invest in a full run; revisit the optimizer,
   supervision, or frozen-decoder capacity.

The comparison is one seed and one selected subset. Passing only establishes
plausibility for a full run; it cannot guarantee validation quality. No budget,
threshold, subset, or decoding rule may be changed after results are observed.
