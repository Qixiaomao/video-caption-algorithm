## Frozen design choices independent of the pilot

- Data: MSR-VTT v1.0 from the pinned ZIP; original full train 6,513, val 497, test 2,990 lists and their recorded hashes. Train/val raw 768-dimensional ViT-B/16 feature cache only; no test model computation before the validation freeze.
- Model: original local GPT-2 Small and pretrained ViT-B/16, new MSR-VTT projection/mapper initialization per seed. No MSVD trained mapper checkpoint. Frozen GPT-2 and ViT backbone; trainable `encoder.proj` and `decoder.mapper` only.
- Frozen ViT feature precision: cuDNN TF32 enabled, CUDA matmul TF32 disabled, matching the completed train/val cache. A smoke attempt with cuDNN TF32 disabled produced a 0.012 live/cache mismatch, so the independent adapter and eventual test cache must assert the matching setting and feature equivalence.
- Arms: A uses causal caption cross-entropy; B adds the previously checked symmetric multi-positive InfoNCE with weight **0.10**, temperature **0.07**, normalized mean visual prefix and frozen GPT-2 token-embedding mean. Exact caption equality determines extra positives, so identical captions are not false negatives. CPR is not part of this experiment.
- Seeds: **123, 124, 125**. Within each seed, A and B share an exact initial state, ordered video batches, per-video reference choices, principal RNG state, optimizer settings and step count. Each epoch is 813 distinct eight-video batches plus a final nine-video batch, covering 6,513 IDs once. A/B trace hashes and per-step RNG evidence must match. Each row of the InfoNCE mask must have at least one legal positive and negative.
- Caption policy: one balanced reference per video per epoch under a deterministic per-video permutation. Local GPT-2 token audit found a 74-token train caption; `max_len=96` including the preserved EOS is fixed for both arms. First caption token and first EOS are supervised; repeated EOS padding is ignored. No caption is silently truncated.
- Optimizer: AdamW, learning rate `3e-4`, weight decay `0.01`, physical batch 8 except the registered final batch of 9. No learning-rate, InfoNCE or CPR search.
- Test decode and metrics: `experiments/msrvtt_test_eval_config_20260928.json`, frozen before formal training at SHA-256 `ec2edd8239db2711ad85698da757af43c4ebf6625d6edf22e0d055bbd8682d28`. Captioning test2990 and its matched 2,990-video/59,794-caption retrieval are named accurately; this is not the 1K retrieval benchmark. Test results cannot select checkpoint, epoch, loss or decode.

`scripts/run_msrvtt_train_val_pilot_20260928.py` completed five full paired A/B visits over train, including the nine-video final batch. `runs/msrvtt_train_val_pilot_20260928/result.json` reports 4,070 steps per arm, exact paired trace, A/B mean step times **0.3387/0.3456 s**, and 2,830 MiB peak reserved GPU memory. The 20-epoch/16,280-step reference-coverage floor is **not** automatically sufficient: we froze **30 epochs/24,420 steps per arm** so every caption is covered by epoch 20 and the following ten balanced visits add another half reference cycle, without using test. It took **27.305 s**, or a linear **424.084 s per 497-video milestone**. This is an estimate, not a guaranteed full-val runtime. The benchmark did not read test or select a model. Source data, smoke, pilot, timing, GPT-2 and test protocol SHA-256 values are pinned in the frozen JSON. ## Planned validation and failure interpretation

The formal independent runner is `scripts/run_msrvtt_ab_formal_20260928.py`. At frozen milestones it records checkpoints before validation, all 497 val videos and references, native vs wrong visual prefix diagnostics, caption diversity, reference NLL, retrieval with the same val video/caption pool, train curves and resource use. The pre-run caption viability rule will keep the MSVD proportions: nonempty rate 1.0; unique rate ≥0.30; largest template rate ≤0.25; positive wrong-prefix mismatch for at least 80% of 497 val videos (398); paired bootstrap lower 95% bound for wrong-minus-native NLL >0. The 398 count is a proportional translation of the old 80/100 rule, not a test-tuned number. The reused MSVD function's embedded 80-video flag is legacy output only; the independent `caption_gate` field is authoritative for this dataset. Pairwise B harms in NLL and reference token F1 will be separately compared with the existing `A+0.15` and `A−0.05` tolerances.

Technical completion, caption-gate passage and paper-claim support are separate. A valid B loss, failed caption gate, or negative B−A retrieval difference remains a reported result. The registered cross-dataset direction claim requires all B caption gates, positive mean B−A val T2V R@1, and at least two of three positive paired seeds; it is not a significance test or a claim that captions improved. The validation conclusion is frozen before one common test2990 run. If an arm crashes, preserve its logs/checkpoints and resume only from a full compatible model/optimizer/RNG/loader checkpoint; otherwise invalidate and rerun the entire paired unit under a new run identity. Never splice inconsistent traces or overwrite the old attempt.
