Record the full commit SHA or an actual released version when reporting which
code you used. A moving branch name alone does not identify a fixed snapshot.

The citation metadata describes software authorship. It does not assert a

## Add the software to an ORCID record

ORCID supports **Software** as a work type, including source-code programs.
A DOI is not required for manual entry:

1. Sign in to ORCID and open **Works > +Add > Add work manually**.
2. Select **Software** as the work type.
3. Enter the software title, **Video captioning and retrieval on a 4 GiB GPU**,
   and its repository URL:
   <https://github.com/Qixiaomao/video-caption-algorithm>.
4. Use the actual author and release metadata for the work being listed.
   Do not use a manuscript revision number as the software version or invent a DOI.
5. Choose the record's visibility and save the software entry.

ORCID records the research output; the code remains hosted on GitHub.
If a later software release is archived with Zenodo, its issued DOI can be
added to the software record. A software record is separate from a journal
article record.
